### 1.2 Apple × Google 精致细节规范（提升画面高级感的关键）
- **画幅与视角**：`9:16` 竖屏纯平 UI 界面设计稿（推荐 `1024x1792` 或最高清 9:16 尺寸），**100% 铺满画布的 2D Flat Mobile UI Screenshot**。
  - **严禁**：3D 手机外壳/边框、斜拍透视、手拿手机、桌面场景、光斑水印、**微信小程序右上角 `•••` / `◎` 胶囊**。
  - 顶部仅保留极简现代手机状态栏（如 `9:41`，Wi-Fi、信号、电量，字体细腻干净）。
- **圆角与留白（Material 3 + iOS 18 韵律）**：
  - 卡片统一大圆角（`14dp`–`20dp`），BottomSheet 顶部 `24dp` 大圆角 + 居中精致灰色小横条（Grabber）。

  - 保持充裕的留白与呼吸感，卡片边缘利落干净、对齐精准，绝不拥挤杂乱。
- **图标与字体**：
  - 统一使用 **SF Symbols / Material Symbols Rounded** 风格的极简圆润线性图标（细线柔和，统一风格）。
  - 现代无衬线中文界面字体（苹方 / 思源黑体风格），字重层级明确（标题 SemiBold、卡片 Medium、辅助 Regular），**数字采用清晰对齐的现代等宽感字体**，**严禁中文乱码、缺笔划、错别字或怪异字符**。
