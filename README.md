# 行测速算（Susuan）

面向中国公务员考试（国考 / 省考 / 联考）《行测·资料分析》模块的原生 Android 离线速算训练软件（Kotlin + Jetpack Compose + Material 3）。

## 下载安装

前往右侧 **[Releases](https://github.com/littleblacksun/Susuan/releases)** 页面下载最新版 `.apk` 文件直接安装到 Android 手机（支持 Android 8.0 / API 26 及以上，完全离线运行，零广告零权限侵入）。

## 核心功能

- **晴空蓝白 3-Tab 现代界面**：`速算`（工作台）· `公式`（独立公式本 + 多维速查）· `统计`（成长数据与历史复盘）。
- **17 种行测预设题型 + 自定义出题**：
  - **除法估算（5 项）**：五位数除三位数、三位数除四位数（默认 `%` 比重作答）、三位数除两位数、三位数除一位数、乘法估算。
  - **加减基础（7 项）**：两位数加减、凑整百练习、三位数加法、三位数减法、三位数加减、多数相加、混合加减。
  - **乘法速算（5 项）**：两位数乘一位数、三位数乘一位数、两位数乘 11、两位数乘 15、两位数乘两位数。
  - **自定义出题**：自由配置运算类型、操作数位数（1~5 位）、负数开关、百分比开关与误差档位。
- **高精度误差判题引擎**：基于 `BigDecimal` 实现精确模式（0 误差）与估算相对误差三档判题（`精算 ±1%` / `实战 ±2%` / `宽松 ±5%`）。
- **沉浸式刷题体验**：
  - 自定义 4×4 悬浮白键帽数字键盘（支持 `正序 / 倒序 / 乱序` 实时切换，全程不弹系统输入法）。
  - 蓝点阵手账手写草稿画布（支持触控笔与手指流畅演算，配撤销 / 清空 / 笔触粗细 / 收起工具条）。
  - `N-back`（1-back / 2-back）工作记忆训练模式。
  - 练习报告环形正确率仪表盘、逐题复盘与一键 **错题重练**。
- **独立「公式本」与多维速查表**：
  - 内置 30 条行测资料分析高频公式（Room 离线持久化），支持搜索、分类、收藏置顶、新建/编辑（含光标快捷数学符号插入栏）、删除。
  - 整合 49 组基础与拓展百化分及反推三招、32 组年均增长率 `(1+r)ⁿ` 幂次矩阵、15 组常用平方数（`11²~25²`）、截位误差口诀及 8 大易错概念。
- **真实练习卷导出**：
  - **PDF 打印卷**：A4 双列自动分页 + 可选独立参考答案与误差区间页。
  - **高清长图**：晴空蓝白风格长图，Android 10+ 零权限直存相册并支持一键分享。
  - **纯文本复制**：整齐排版一键写入剪贴板。

## 技术栈

- **语言与 UI**：Kotlin 2.0.20 · Jetpack Compose (BOM 2024.09.00) · Material 3 · Navigation Compose 2.8.0
- **本地持久化**：Room 2.6.1 (KSP) · DataStore Preferences 1.1.1
- **构建环境**：Gradle 8.7 · AGP 8.5.2 · JDK 21 · Android SDK 34 (`minSdk = 26`, `targetSdk = 34`)

## 本地构建

```bash
./gradlew testDebugUnitTest assembleDebug
```
